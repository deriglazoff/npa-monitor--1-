04 / 09

Что выяснилось в работе

Два вывода, которые экономят вам деньги

Первое

Эмулятор браузера не нужен

Изначально предполагалось, что порталы придётся обходить через программу-браузер — это тяжёлый и капризный в поддержке компонент. Проверка показала: все три сайта отдают данные обычными запросами. Решение получилось легче и дешевле в сопровождении.

Второе

Российский адрес нужен только одному сайту

Сайт Госдумы не принимает обращения из-за рубежа, поэтому при разработке использовался посредник с российским адресом. При запуске из России он не нужен вовсе. Важная деталь: тот же посредник ломает два других портала — они его блокируют, поэтому маршрут задаётся отдельно для каждого источника.

Практический смысл: при работе внутри РФ решение не требует ни браузерного движка, ни платных посредников — только сам скрипт.

05 / 09

Границы решения

Что пилот не делает

Названо прямо, чтобы вы не рассчитывали на то, чего нет.

  • Портал проектов НПА даёт только перечень идентификаторов — без наименований и ведомств.
  • Отбор идёт по заголовку документа. Если тема раскрывается только в тексте, а в названии её нет, документ не попадёт в выборку.
  • Публикация принятых актов на pravo.gov.ru в задание не входила и не охвачена.
  • Пилот собирает срез по запросу. Постоянное наблюдение — отдельный этап, см. следующий лист.

Оговорка о датах: документ попадает в выборку по событию внутри периода, а в колонке «дата смены статуса» стоит последнее известное событие — оно может быть позже конца недели. Это не ошибка, а признак того, что документ с тех пор продвинулся.

Следующий этап

Постоянное наблюдение строится иначе

Не «каждую неделю запрашивать архив», а снимать срез ежедневно и сравнивать со вчерашним.

Шаг 1

Ежедневный срез

Программа снимает состояние порталов раз в сутки.

→

Шаг 2

Сравнение

Что изменилось за неделю — считается разницей между срезами.

→

Шаг 3

Отчёт

Только новое и изменившееся, по вашим направлениям.

Почему так: архивные фильтры по датам — самая хрупкая часть госпорталов. У Банка России такой фильтр уже не работает, у портала НПА данных нет вовсе. При ежедневном срезе вы от их фильтров не зависите, а история изменений копится у вас.

07 / 09

Работы к обсуждению

Что предлагаем дальше

Закрыть третий портал

  • Наименования, ведомства, статусы и даты проектов НПА.
  • Путь известен, требуется разбор обмена данными в живом браузере.
  • Оценка: до одного рабочего дня.

Перевести в постоянный режим

  • Ежедневный сбор, накопление истории, отчёт раз в неделю.
  • Сигнал, если сбор вернул пустоту — портал переверстали.
  • Оценка обсуждается после решения по объёму.

Важно для постоянного режима: сигнал о пустом срезе обязателен. Без него переверстанный портал молча перестанет отдавать данные, и пробел накопится незаметно.

Для вашего технического специалиста

Как запустить у себя

  1. Установить зависимости: pip install -r requirements.txt
  2. Проверить доступность порталов: python -m npa_monitor doctor
  3. Собрать за период:
    python -m npa_monitor collect --from 29.06.2026 --to 05.07.2026

Настройка без программиста

Тематические направления и ключевые слова вынесены в файл config.yaml. Чтобы сузить или расширить охват, правится только он — код трогать не нужно.

При запуске из России в файле настроек нужно указать прямой доступ для всех источников. Полное описание, включая разбор каждого портала и известные ограничения, — в файле README.md внутри проекта.
